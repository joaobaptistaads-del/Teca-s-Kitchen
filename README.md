# Teca's Kitchen - Sistema Completo de Gestão de Restaurante

Sistema completo de gestão de restaurante com frontend público e painel administrativo.

## Stack Tecnológica

- **Frontend**: React + Vite
- **Backend**: Node.js + Express
- **Banco de Dados**: Supabase
- **Autenticação**: JWT

## Funcionalidades

### Site Público (Sem login necessário)
- Visualização do cardápio
- Informações do restaurante
- Contato e redes sociais

### Painel Administrativo (Com autenticação)
- Dashboard com análises em tempo real
- Gestão de produtos/cardápio
- Sistema de vendas
- Gestão financeira (entradas e saídas)
- Configurações do site
